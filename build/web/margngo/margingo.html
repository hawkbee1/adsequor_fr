❓ Aide & à propos

À quoi sert cet outil ?

MarginGo est un calculateur de coût de revient pour le transport routier de marchandises (TRM). Il permet de :

  • chiffrer le coût d'un trajet (carburant, péages, conducteur, véhicule, frais de structure) ;
  • calculer un prix de vente HT avec une marge cible et obtenir un €/km de référence ;
  • garder un historique des trajets simulés ;
  • éditer une lettre de voiture (CMR national ou international) à partir d'un trajet enregistré.

Comment démarrer ?

  1. Onglet 🏢 Entreprise — saisir raison sociale, dépôt, paramètres généraux.
  2. Onglet 🚛 Véhicules — ajouter au moins un véhicule (tracteur, porteur, VUL…).
  3. Onglet 👷 Conducteur — ajouter au moins un conducteur avec salaire et statut.
  4. Onglet 🛣️ Calcul d'un trajet — saisir départ / arrivée, sélectionner véhicule et conducteur, lancer le calcul.
  5. Onglet 📜 Historique — consulter, éditer, exporter en PDF ou générer une CMR.

💡 Astuce : dans l'onglet Entreprise, bouton "🎬 Charger démo" pour pré-remplir l'outil avec un jeu de données d'exemple et tester rapidement.

Où sont stockées mes données ?

Localement dans votre navigateur, via le localStorage. Rien n'est envoyé sur Internet, sauf les requêtes externes nécessaires : OpenStreetMap (recherche d'adresse), OSRM (itinéraire), recherche-entreprises.api.gouv.fr (SIRET), et data.economie.gouv.fr (prix carburant).

⚠️ Important : vider le cache du navigateur, utiliser le mode privé ou changer de poste/navigateur vous fait perdre vos données. Exportez régulièrement une sauvegarde via le bouton "📦 Exporter" de l'onglet Entreprise.

📤 Partager mes données / changer d'ordinateur

L'application est un fichier HTML autonome. Pas d'installation, pas de Visual Studio Code, pas de compte. Pour la déplacer ou la partager :

  1. Copier 2 fichiers sur clé USB, Drive ou par email :
    • margngo.html (l'application elle-même)
    • peagecalc_86.html (le moteur de calcul des péages, dans le même dossier)
  2. Double-cliquer sur margngo.html sur le nouveau poste : ça s'ouvre dans le navigateur (Chrome, Firefox, Edge, Safari).
  3. Pour récupérer ses données : onglet Entreprise → 📥 Importer → choisir le fichier margngo_backup_*.json exporté depuis l'autre poste.

💡 À retenir : le HTML = le programme (toujours le même). Le JSON = vos données (à transférer séparément). Les deux fichiers se complètent : sans le JSON, l'app est vide ; sans le HTML, le JSON n'est pas lisible.

⚠️ Travail à plusieurs / multi-postes : chaque poste a sa propre base. Pour vraiment partager en temps réel entre plusieurs personnes (toi + exploitant + comptable par ex.), une version connectée à un serveur sera nécessaire — ce n'est pas le cas dans cette version prototype.

À propos du module CMR

L'éditeur de lettre de voiture génère un PDF conforme aux mentions obligatoires de l'art. 6 de la Convention CMR (Genève, 1956) en mode international, ou aux exigences nationales françaises en mode national.

⚠️ Limite juridique importante : le PDF généré ne constitue PAS un eCMR opposable au sens du Protocole additionnel CMR de 2008. Une signature électronique qualifiée eIDAS et un tiers archiveur sont requis pour cela (TransFollow, Pledg, Alpega...). L'outil est utile pour :

  • imprimer une CMR papier pré-remplie à signer manuellement (juridiquement valable) ;
  • tester / prototyper un workflow ;
  • générer une trace interne dans son TMS.

🛣️ Roadmap (évolutions prévues)

  • Routing PL professionnel — passage d'OSRM à un moteur type TomTom Move ou PTV Map&Guide pour des durées réalistes avec restrictions poids/hauteur et trafic temps réel.
  • Calculateur TCO décarbonation — comparatif diesel vs GNV vs électrique vs B100 sur 5-7 ans, incluant fiscalités (TICPE réduite B100, accise GNV, exonération TICFE PL électrique) et suramortissement art. 39 decies A du CGI.
  • Altimétrie — surconsommation selon profil de relief (formule ADEME/COPERT + données SRTM).
  • eCMR opposable — intégration d'une signature électronique qualifiée eIDAS via tiers de confiance (TransFollow, Pledg…).
  • Synchronisation multi-postes — backend serveur pour partager une base entre l'exploitant, le comptable et le dirigeant.

Limites et bonnes pratiques

  • Les valeurs par défaut (TICPE, péages, charges sociales, SMIC) sont calibrées France 2025-2026.
  • Les calculs de péage utilisent les grilles tarifaires SCA TTC et basculent en HT pour le coût de revient (TVA récupérable par les transporteurs assujettis).
  • L'API recherche-entreprises ne retourne pas toujours le nom commercial (champ INSEE optionnel) — l'outil croise avec OpenStreetMap pour combler.
  • OSRM (itinéraires) est un service public communautaire — pas de SLA.

⚖️ Réglementation Sociale

Deux régimes coexistent en France selon le PTAC du véhicule :
🚛 Véhicules > 3,5 t (PL/SPL) → Règlement (CE) n° 561/2006 (temps de conduite, pauses, repos) + Directive 2002/15/CE (temps de travail).
🚐 Véhicules ≤ 3,5 t (messagerie, livraison urbaine) → Code du travail français et convention collective TRM (IDCC 16). Le RGT 561/2006 ne s'applique pas.

🚛 PARTIE 1 — Véhicules > 3,5 t (Règl. 561/2006)

S'applique à tout véhicule de plus de 3,5 t, quelle que soit l'activité (longue distance, courte distance, messagerie en PL, distribution...).
